###### 문제 설명

전화번호가 문자열 phone_number로 주어졌을 때, 전화번호의 뒷 4자리를 제외한 나머지 숫자를 전부 `*`으로 가린 문자열을 리턴하는 함수, solution을 완성해주세요.

- phone_number는 길이 4 이상, 20이하인 문자열입니다.

|"027778888"|"*****8888"|

### 문제 해석
* 예외에서 보면 번호가 4개 이상 20 이하인 문자열 이니
	* 4개면 그냥 번호 그대로 return

* 4개 이상일 경우, 앞에는 그냥 * 로 채우고, 
	* int numToStar = phone_number.length() - numToDp; 통해서 몇번 째 부터가 마지막 4 digit인지 확인하고 번호 출력.


---
## 정답 소스 코드
```cpp
#include <string>
#include <vector>

using namespace std;

string solution(string phone_number) {

    string answer = "";

    int numToDp = 4;

    if (numToDp == phone_number.length())
    {
        return answer = phone_number;
    }

    vector<char> v;

    int numToStar = phone_number.length() - numToDp;

    // length == 4 ~ 20
    for (int i = 0; i < phone_number.length(); i++)
    {   
        //cout << i << endl;
        if (i < numToStar)
        {
            v.push_back('*');
            //cout << "Here *" << endl;
        }            
        else
        {
            //cout << phone_number[i] << endl;
            v.push_back(phone_number[i]);
        }

        answer += v[i];
    }

    
     return answer;
}

```
