###### 문제 설명

두 수의 최소공배수(Least Common Multiple)란 입력된 두 수의 배수 중 공통이 되는 가장 작은 숫자를 의미합니다. 예를 들어 2와 7의 최소공배수는 14가 됩니다. 정의를 확장해서, n개의 수의 최소공배수는 n 개의 수들의 배수 중 공통이 되는 가장 작은 숫자가 됩니다. n개의 숫자를 담은 배열 arr이 입력되었을 때 이 수들의 최소공배수를 반환하는 함수, solution을 완성해 주세요.

##### 입출력 예

|arr|result|

|[2,6,8,14]|168|
|[1,2,3]|6|

### 힌트

- **두 수의 관계 활용하기**  
    두 수의 최소공배수는 **두 수를 곱한 값에서 두 수의 최대공약수(GCD)를 나눈 값**과 같습니다. 예를 들어 6과 8의 최대공약수는 2이므로, 최소공배수는 (6 곱하기 8) 나누기 2를 해서 24가 됩니다.
- **최대공약수 쉽게 구하기**  
    C++17 표준부터는 `<numeric>` 헤더를 포함하면 `std::gcd`라는 함수를 바로 사용할 수 있습니다. 이 함수를 사용하면 두 수의 최대공약수를 한 줄로 간단하게 구할 수 있습니다.
- **여러 수로 확장하기**  
    배열에 있는 모든 수의 최소공배수를 구하려면 순서대로 누적 계산을 하면 됩니다. 처음 두 수의 최소공배수를 구한 뒤, **그 결과값과 다음 숫자의 최소공배수**를 구하는 과정을 배열의 마지막 원소까지 반복합니다.
- **자료형 주의하기**  
    숫자들을 곱하는 과정에서 잠시 값이 커질 수 있으므로, 안전하게 계산하기 위해 `최소공배수 = (A 나누기 최대공약수) 곱하기 B` 형태로 나누기를 먼저 하거나 큰 정수 자료형을 사용하는 것이 좋습니다.

## 정답 소스 코드
```cpp
#include <vector>
#include <numeric> // std::gcd를 사용하기 위해 포함합니다.

using namespace std;

// 두 수의 최소공배수(LCM)를 구하는 함수입니다.
long long get_lcm(long long a, long long b) {
    // (a * b) / gcd(a, b) 계산 시 오버플로우를 방지하기 위해 나누기를 먼저 합니다.
    return (a / std::gcd(a, b)) * b;
}

int solution(vector<int> arr) {
    // 기준이 될 첫 번째 원소로 시작합니다.
    long long answer = arr[0];
    
    // 두 번째 원소부터 마지막 원소까지 순서대로 최소공배수를 누적해 나갑니다.
    for (size_t i = 1; i < arr.size(); ++i) {
        answer = get_lcm(answer, arr[i]);
    }
    
    return answer;
}


```
