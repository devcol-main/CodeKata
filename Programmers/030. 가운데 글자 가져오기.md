###### 문제 설명

단어 s의 가운데 글자를 반환하는 함수, solution을 만들어 보세요. 단어의 길이가 짝수라면 가운데 두글자를 반환하면 됩니다.

###### 재한사항

- s는 길이가 1 이상, 100이하인 스트링입니다.

##### 입출력 예

|s|return|
|---|---|
|"abcde"|"c"|
|"qwer"|"we"|

## 문제 풀이 과정

### 문제 해석
* string.length() ->들어오는 문자열의 길이 확인
* n %2 ==0 -> 짝수인지 아닌지 확인
* 짝수의 경우 중간 2개의 문자 출력, 아니면 중간 문자만 출력
* string은 마치 char의 배열처럼 사용가능

---
## 정답 소스 코드
```cpp
#include <string>
#include <vector>

using namespace std;

string solution(string s) {
    string answer = s;

    int n = s.length();   
    int div = n / 2;

    if (n % 2 == 0)
    {
        answer = s[div - 1];
		return answer += s[div];
    }
    else
    {
        return answer = s[div];
    }
}
```

## Comments:

* 처음에 string을 한번에 더해서 answer 로 리턴 하려 했는데 이상한 문자가 출력됨. 아마 그렇게 하면 아스키넘버가 이상한게 나오는 거같아서 두부분으로 따로 하니깐 정상 출력.
