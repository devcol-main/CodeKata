###### 문제 설명

자연수 n을 뒤집어 각 자리 숫자를 원소로 가지는 배열 형태로 리턴해주세요. 예를들어 n이 12345이면 [5,4,3,2,1]을 리턴합니다.

##### 제한 조건

- n은 10,000,000,000이하인 자연수입니다.

##### 입출력 예

|n|return|
|---|---|
|12345|[5,4,3,2,1]|
---

```cpp
#include <string>
#include <vector>

using namespace std;

vector<int> solution(long long n) {
    vector<int> answer;
    return answer;
}
```

## 문제 풀이 과정

### 문제 나누기
* 자연수가 들어옴
* 순서를 뒤집어서 
* 각 자리 숫자를 원소로 가지고 있는 배열 형태로 리턴
*
### 문제 해석
들어오는 자연수를 1의 자리 부터 배열에 넣은 뒤에 리턴 하면 된다.
* 123 이 들어 왔을 때 [3,2,1]. 즉 1의 자리 먼저 배열에 넣으면 된다.
* 자연수 의 일의 자를 구하는 법은:  n % 10; (% 은 나머지 구하기니 **modulo operator** or **remainder operator**)
	* 123 % 10: 3 | 12 % 10: 2 | 1 % 10 :1
* 구한건 배열에 push_back 해서 넣고.
* 일의 자리 수를 구했으니 10의 자리 수를 구해야 하는데 여기선, 일의 자릿수를 없애고 (이미 구한건 배열에 넣었으니) 십의 자리 수를 일의 자릿수로 만들면 된다.
* 일의 자릿수 없애기: n / 10; 
	* 123 / 10: 12.3 (정확하게는 12.3 으로 나오지만, 여기서는 정수형으로 나타나게 되면 소수점 아래는 버려지기 때문에 신경 안쓰면된다.)



---
### 정답 소스 코드
```cpp
#include <string>
#include <vector>

using namespace std;

vector<int> solution(long long n) 
{
    vector<int> answer;
    while (n > 0)
    {
        answer.push_back(n % 10); 
        n /= 10;
    }   
    return answer;
}

```
