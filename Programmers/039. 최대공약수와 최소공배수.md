###### 문제 설명

두 수를 입력받아 두 수의 최대공약수와 최소공배수를 반환하는 함수, solution을 완성해 보세요. 배열의 맨 앞에 최대공약수, 그다음 최소공배수를 넣어 반환하면 됩니다. 예를 들어 두 수 3, 12의 최대공약수는 3, 최소공배수는 12이므로 solution(3, 12)는 [3, 12]를 반환해야 합니다.

##### 제한 사항

- 두 수는 1이상 1000000이하의 자연수입니다.

##### 입출력 예

|n|m|return|
|---|---|---|
|3|12|[3, 12]|
|2|5|[1, 10]|

##### 입출력 예 설명

입출력 예 #1  
위의 설명과 같습니다.

입출력 예 #2  
자연수 2와 5의 최대공약수는 1, 최소공배수는 10이므로 [1, 10]을 리턴해야 합니다.

---

```cpp
#include <string>
#include <vector>

using namespace std;

vector<int> solution(int n, int m) {
    vector<int> answer;
    return answer;
```

### 힌트

#### 최대공약수 (Greatest Common Divisor, GCD)
는 두 개 이상의 정수에서 공통된 약수(공약수) 중 가장 큰 수
* 정의: 0이 아닌 두 개 이상의 정수를 모두 나누어떨어지게 하는 가장 큰 정수.
* 예시로 두 수 12, 18의 공약수 및 최대공약수를 찾고 싶다고 하자. 간단하게, 두 수의 약수를 모두 나열한다.

* 	12: 1, 2, 3, 4, 6, 12  
		18: 1, 2, 3, 6, 9, 18

* 여기서 위아랫줄 모두 같이 있는 숫자가 **공약수**가 된다. 즉, 이 경우에는 1, 2, 3, 6이 공약수가 된다. **최대공약수**는, 찾은 공약수 중 가장 큰 것, 즉 이 경우에는 6이 최대공약수가 된다.

1. 소인수분해 이용 (공식)

각 숫자를 소인수분해한 후, 공통된 소인수 중에서 지수가 작거나 같은 것을 택하여 곱합니다. 

- **예시:** 60과 48의 최대공약수
    - \(60 = 2^2 x 3 x 5)
    - \(48 = 2^4 x 3)
    - 공통 소인수: \(2, 3\) (지수가 작은 것 선택: \(2^2, 3^1\))
    - 최대공약수: \(2^2 x 3 = 12\) 

2. 유클리드 호제법 (빠른 계산법)

두 수 \(a, b\) (\(a > b\))에 대해, \(a\)를 \(b\)로 나눈 나머지 \(r\)을 구하고, \(b\)와 \(r\)의 최대공약수를 구하는 과정을 나머지가 0이 될 때까지 반복합니다. 

- **예시:** 1071과 1029의 최대공약수
    1. \(1071 / 1029 = 1 .... 42)
    2. \(1029 / 42 = 24 ... 21)
    3. \(42 / 21 = 2 ... 0)
    4. 나머지가 0이므로 최대공약수는 **21** 

3. 기타 방법

* **공약수로 나누기:** 1 이외의 공약수가 없을 때까지 나눈 후, 나눈 공약수들을 모두 곱합니다.
* **최대공약수와 최소공배수 관계:** 두 수의 곱 = 최대공약수 x 최소공배수


#### C++ 에서 최대공약수 (Greatest Common Divisor, GCD)는
* 유클리드 호제법(GCD(a, b) = GCD (b, a (mod b))을 활용하여 구하며, `<numeric>` 헤더의 `std::gcd` 함수를 사용하는 것이 가장 효율적
- **가장 간단한 방법 (C++17 이상):** `#include <numeric>` 후 `std::gcd(a, b)` 사용.
- **재귀 함수 (유클리드 호제법):** `int gcd(int a, int b) { return b ? gcd(b, a % b) : a; }`.
- **반복문 (유클리드 호제법):** 나머지가 0이 될 때까지 큰 수를 작은 수로 나눈 나머지를 취함

#### 최소공배수 (Least Common Multiple, LCM)
는 2개 이상의 자연수에서 공통된 배수(공배수) 중 가장 작은 수


**1. 최소공배수 구하는 방법**

- **배수 나열법:** 각 수의 배수를 나열하여 가장 먼저 겹치는 수를 찾습니다 (예: 5와 6의 최소공배수는 30).
- **소인수분해 활용:** 각 수를 소인수분해한 후, 공통인 소인수 중 지수가 큰 것과 공통되지 않은 소인수를 모두 곱합니다.
- **나눗셈 이용:** 1 이외의 공약수로 각 수를 나누고, 더 이상 나눌 수 없을 때까지 나눈 뒤 왼쪽과 아래쪽의 수들을 모두 곱합니다.
- **최대공약수(GCD) 활용:** 두 수의 곱을 최대공약수로 나눕니다:

---
C++17 이상 부터는 \<numberic\> 해더에 gdc 랑 lcm 있어서 그냥 사용하면됨.

* lcm( ) // 최소공배수 (Least Common Multiple, LCM)

## 정답 소스 코드
```cpp
#include <string>
#include <vector>

#include <numeric>

using namespace std;

vector<int> solution(int n, int m) {
    vector<int> answer;

    int g = gcd(n, m);
    int l = lcm(n, m);
    
    return answer = { g,l };
}

```
