###### 문제 설명

H-Index는 과학자의 생산성과 영향력을 나타내는 지표입니다. 어느 과학자의 H-Index를 나타내는 값인 h를 구하려고 합니다. 위키백과[1](https://school.programmers.co.kr/learn/courses/30/lessons/42747?language=cpp#fn1)에 따르면, H-Index는 다음과 같이 구합니다.

어떤 과학자가 발표한 논문 `n`편 중, `h`번 이상 인용된 논문이 `h`편 이상이고 나머지 논문이 h번 이하 인용되었다면 `h`의 최댓값이 이 과학자의 H-Index입니다.

어떤 과학자가 발표한 논문의 인용 횟수를 담은 배열 citations가 매개변수로 주어질 때, 이 과학자의 H-Index를 return 하도록 solution 함수를 작성해주세요.

##### 제한사항

- 과학자가 발표한 논문의 수는 1편 이상 1,000편 이하입니다.
- 논문별 인용 횟수는 0회 이상 10,000회 이하입니다.

##### 입출력 예

|citations|return|
|---|---|
|[3, 0, 6, 1, 5]|3|

##### 입출력 예 설명

이 과학자가 발표한 논문의 수는 5편이고, 그중 3편의 논문은 3회 이상 인용되었습니다. 그리고 나머지 2편의 논문은 3회 이하 인용되었기 때문에 이 과학자의 H-Index는 3입니다.

## 문제 풀이 과정

- **정렬(Sort)의 필요성**
    - 논문을 인용 횟수가 높은 순서대로 정렬하면 H-Index를 찾기가 매우 수월해집니다.
    - 예를 들어 `[3, 0, 6, 1, 5]`라는 배열이 있다면, 내림차순 정렬 시 `[6, 5, 3, 1, 0]`이 됩니다.
- **조건 비교하기**
    - 정렬된 배열을 앞에서부터 하나씩 확인합니다. (이때 논문의 개수를 나타내는 가상의 번호를 1번부터 매깁니다.)
    - 1번째 논문: 6회 인용 (\(\ge 1\)이므로 가능)
    - 2번째 논문: 5회 인용 (\(\ge 2\)이므로 가능)
    - 3번째 논문: 3회 인용 (\(\ge 3\)이므로 가능)
    - 4번째 논문: 1회 인용 (\(1 < 4\)이므로 불가능)
    - 따라서 조건을 만족하는 최대 논문 개수인 **3**이 H-Index가 됩니다.
- **C++ 내림차순 정렬 방법**
	- rbegin() rend() 혹은
    - `sort(citations.begin(), citations.end(), greater<int>());`를 사용하면 간결하게 내림차순 정렬을 할 수 있습니다.

## 정답 소스 코드
```cpp
#include <string>
#include <vector>
#include <algorithm>

using namespace std;

int solution(vector<int> citations) 
{
    int answer = 0;

    sort(citations.rbegin(),citations.rend());

    int index = 1;

    for(const auto& it : citations)
    {
        if(it >= index)
        {
            answer++;
        }
        else
        {
            return answer;        
        }

        index++;
    }
    

    return answer;
}

```

```cpp
#include <string>
#include <vector>
#include <algorithm>

using namespace std;

int solution(vector<int> citations) {
    int answer = 0;
    
    // 1. 인용 횟수를 내림차순(큰 값부터 순서대로) 정렬
    sort(citations.begin(), citations.end(), greater<int>());
    
    // 2. 정렬된 배열을 돌며 H-Index의 최댓값 찾기
    for (int i = 0; i < citations.size(); i++) {
        // (i + 1)은 현재까지 확인한 논문의 편수입니다.
        // 현재 논문의 인용 횟수가 현재 논문 편수 이상이어야 합니다.
        if (citations[i] >= i + 1) {
            answer = i + 1;
        } else {
            // 정렬되어 있으므로, 조건을 만족하지 않기 시작하면 
            // 그 뒤의 논문들도 절대 조건을 만족할 수 없습니다.
            break;
        }
    }
    
    return answer;
}
```
