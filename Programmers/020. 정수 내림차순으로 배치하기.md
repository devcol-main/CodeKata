## 문제 풀이 과정


### 문제 해석

매개변수의 1의 자리 씩 넣고 배열에 넣고, 지우고 반복
* (n % 10); // n 의 1 의 자리 넣기
* n /= 10; // n 의 1 의 자리 지우기

배열의 순서를 정렬
* sort(temp.begin(), temp.end());
// 1,1,8,3,7,2-> 1,1,2,3,7,8

이제 역순으로 정렬된 하나의 자연수로 반환

for (auto order : temp)
{    
    answer += (order * multiple);
    multiple *= 10;
        
}


---
### 정답 소스 코드
```cpp
#include <string>
#include <vector>

#include <algorithm>

using namespace std;

long long solution(long long n) {
    long long answer = 0;

    vector<long> temp;
    
    while (true)
    {
        
        if (n > 0)
        {            
            temp.push_back(n % 10);            
            n /= 10; 
        }
        else
        {
            break;
        }        
        
    }
    
    sort(temp.begin(), temp.end());    

    int multiple = 1;

    for (auto order : temp)
    {    
        answer += (order * multiple);
        multiple *= 10;
        
    }
    return answer;
}

```
