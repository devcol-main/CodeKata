###### 문제 설명

피보나치 수는 F(0) = 0, F(1) = 1일 때, 1 이상의 n에 대하여 F(n) = F(n-1) + F(n-2) 가 적용되는 수 입니다.

예를들어

- F(2) = F(0) + F(1) = 0 + 1 = 1
- F(3) = F(1) + F(2) = 1 + 1 = 2
- F(4) = F(2) + F(3) = 1 + 2 = 3
- F(5) = F(3) + F(4) = 2 + 3 = 5

와 같이 이어집니다.

2 이상의 n이 입력되었을 때, n번째 피보나치 수를 1234567으로 나눈 나머지를 리턴하는 함수, solution을 완성해 주세요.

##### 제한 사항

- n은 2 이상 100,000 이하인 자연수입니다.

##### 입출력 예

|n|return|

|3|2|
|5|5|

##### 입출력 예 설명

피보나치수는 0번째부터 0, 1, 1, 2, 3, 5, ... 와 같이 이어집니다.

## 문제 풀이 과정


### 1단계: 나머지 연산의 성질 활용하기

피보나치 수는 \(n\)이 조금만 커져도 자료형(`int`, `long long`)의 표현 범위를 쉽게 초과(오버플로우)합니다.  

나머지 연산은 **더한 후 나머지를 구한 것**과 **각각의 나머지를 더한 후 다시 나머지를 구한 것**이 같습니다.

(A+B) (mod M) = ((A (mod M)) + (B (mod M) )) (mod M)

따라서, 최종 결과에만 `% 1234567`을 하는 것이 아니라, **매 단계에서 더할 때마다 `% 1234567`을 적용**해야 안전합니다.


### 2단계: 반복문(동적 계획법) 선택하기

단순 재귀 함수: \(O(2^n)\)의 시간 복잡도를 가져 제한 시간 내에 통과할 수 없습니다.

반복문(배열/벡터): \(O(n)\)의 시간 복잡도로, \(n = 100,000\)일 때 약 \(100,000\)번의 연산만 수행하므로 매우 효율적입니다.

## 정답 소스 코드
```cpp

#include <vector>

using namespace std;

int solution(int n) {
    // 피보나치 수를 저장할 벡터 선언 (0번부터 n번까지 필요하므로 크기는 n + 1)
    vector<int> f(n + 1);
    
    // 초기값 설정
    f[0] = 0;
    f[1] = 1;
    
    // 반복문을 통해 n번째까지 피보나치 수를 계산
    for (int i = 2; i <= n; i++) {
        // 매 연산마다 1234567로 나눈 나머지를 저장하여 오버플로우 방지
        f[i] = (f[i - 1] + f[i - 2]) % 1234567;
    }
    
    return f[n];
}
```

## Comments:

* 이 문제는 \(n\)이 최대 \(100,000\)까지 주어지므로, 일반적인 재귀 함수(Recursion)를 사용하면 시간 초과와 스택 오버플로우가 발생하기 때문에 주의해야 합니다. 
* 따라서 반복문(Dynamic Programming)을 사용하고, 매 연산마다 나머지 연산 성질을 적용해야 정수 오버플로우를 방지할 수 있습니다.
