###### 문제 설명

두 정수 a, b가 주어졌을 때 a와 b 사이에 속한 모든 정수의 합을 리턴하는 함수, solution을 완성하세요.  
예를 들어 a = 3, b = 5인 경우, 3 + 4 + 5 = 12이므로 12를 리턴합니다.

##### 제한 조건

- a와 b가 같은 경우는 둘 중 아무 수나 리턴하세요.
- a와 b는 -10,000,000 이상 10,000,000 이하인 정수입니다.
- a와 b의 대소관계는 정해져있지 않습니다.

##### 입출력 예

|a|b|return|
|---|---|---|
|3|5|12|
|3|3|3|
|5|3|12|

* a와 b가 같은 경우는 둘 중 아무 수나 리턴하세요. | 라서 그냥 a 로 리턴 하게함.
* 큰 수와 작은 수 확인 후 두개의 차이 만큼 더하기


---
### 정답 소스 코드
```cpp
#include <string>
#include <vector>

using namespace std;

long long solution(int a, int b) {
    long long answer = 0;

    if (a == b)
    {
        return answer = a;
    }

    long long range = 0;
    long long sum=0;

    if (a > b)
    {
        // 큰거 뺴기 작은거 == a 와 b 사이의 간격
        range = a - b;

        // 작은거 부터 range 만큼 더하기 (a&b 포함)

        for (long long i = 0; i <= range;++i)
        {
            sum += b + i;
        }

        return answer = sum;
        
    }

    else if (b > a)
    {

        range = b - a;
        // 작은거 부터 range 만큼 더하기 (a&b 포함)
        for (long long i = 0; i <= range;++i)
        {
            sum += a + i;
        }

        return answer = sum;
    }

}


```

### 더 깔끔한 정답 코드

인터넷에서 가져온 답지


```cpp
#include <string>
#include <vector>
#include <algorithm> // min, max 사용

using namespace std;

long long solution(int a, int b) {
    long long answer = 0;
    
    // 1. 큰 값과 작은 값 설정
    long long min_val = min(a, b);
    long long max_val = max(a, b);
    
    // 2. 등차수열의 합 공식 사용 (효율성)
    // (작은수 + 큰수) * (개수) / 2
    answer = (max_val - min_val + 1) * (min_val + max_val) / 2;
    
    return answer;
}

```

### Comments:
* 처음에 data type 을 long long 이 아니라 습관 적으로 int 로 해서 실패가 떴었다. (제한 조건에 a와 b는 -10,000,000 이상 10,000,000 이하인 정수입니다.) 를 참고 안 했었음.
* 앞으로 제한 조건 을 잘 참고하자.
* #include <algorithm> // min(), max() 를 다음엔 사용해보자
