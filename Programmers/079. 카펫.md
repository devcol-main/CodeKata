Leo는 카펫을 사러 갔다가 아래 그림과 같이 중앙에는 노란색으로 칠해져 있고 테두리 1줄은 갈색으로 칠해져 있는 격자 모양 카펫을 봤습니다.

### 힌트

힌트 (문제 접근법)
**1. 도형의 구조 파악하기**

- 카펫의 전체 가로 길이를 W, 세로 길이를 H라고 가정합니다. 제한사항에 따라 가로(W)는 세로(H)보다 길거나 같습니다.
- 갈색 테두리가 한 줄씩 둘러싸고 있으므로, 중앙에 있는 노란색 격자의 가로 길이는 전체 가로에서 2를 뺀 (W - 2)가 되고, 세로 길이는 전체 세로에서 2를 뺀 (H - 2)가 됩니다.

**2. 방정식 세우기**

- 노란색 격자의 수 공식: yellow = (W - 2) * (H - 2)
- 갈색 격자의 수 공식: 전체 카펫 넓이에서 노란색 격자의 넓이를 빼면 갈색 격자의 수가 나옵니다. 이를 정리하면 brown = (W * H) - yellow가 되며, 다른 표현으로는 brown = 2 * W + 2 * H - 4가 됩니다.

**3. 탐색 방법**

- 노란색 격자의 세로 길이인 (H - 2)를 1부터 시작해서 yellow의 제곱근까지 1씩 늘려가며 확인합니다.
- yellow가 현재 검사 중인 노란색 세로 길이로 나누어떨어질 때만 올바른 직사각형이 됩니다. 이때 노란색 가로 길이는 yellow를 노란색 세로 길이로 나눈 값이 됩니다.
- 이렇게 구한 노란색 가로, 세로 길이에 각각 2를 더해 전체 가로 W와 전체 세로 H를 구합니다.
- 이 W와 H를 갈색 격자의 수 공식인 (2 * W + 2 * H - 4)에 대입했을 때, 문제에서 주어진 brown의 개수와 일치하는지 체크합니다.

## 정답 소스 코드
```cpp

#include <vector>
#include <cmath>

using namespace std;

vector<int> solution(int brown, int yellow) {
    vector<int> answer;
    
    // 노란색 격자의 세로 길이(y_h)는 1부터 시작하여 총 개수의 제곱근까지 탐색
    for (int y_h = 1; y_h <= sqrt(yellow); ++y_h) {
        // yellow가 y_h로 나누어 떨어질 때만 유효한 직사각형
        if (yellow % y_h == 0) {
            int y_w = yellow / y_h; // 노란색 격자의 가로 길이
            
            // 전체 카펫의 가로(W), 세로(H) 계산
            int W = y_w + 2;
            int H = y_h + 2;
            
            // 계산한 크기가 갈색 격자의 수 조건을 만족하는지 확인
            if (2 * W + 2 * H - 4 == brown) {
                answer.push_back(W);
                answer.push_back(H);
                break; // 정답을 찾았으므로 루프 탈출
            }
        }
    }
    
    return answer;
}

```
