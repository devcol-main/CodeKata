JadenCase란 모든 단어의 첫 문자가 대문자이고, 그 외의 알파벳은 소문자인 문자열입니다. 단, 첫 문자가 알파벳이 아닐 때에는 이어지는 알파벳은 소문자로 쓰면 됩니다. (첫 번째 입출력 예 참고)  
문자열 s가 주어졌을 때, s를 JadenCase로 바꾼 문자열을 리턴하는 함수, solution을 완성해주세요.

##### 제한 조건

- s는 길이 1 이상 200 이하인 문자열입니다.
- s는 알파벳과 숫자, 공백문자(" ")로 이루어져 있습니다.
    - 숫자는 단어의 첫 문자로만 나옵니다.
    - 숫자로만 이루어진 단어는 없습니다.
    - 공백문자가 연속해서 나올 수 있습니다.

##### 입출력 예

|s|return|
|---|---|
|"3people unFollowed me"|"3people Unfollowed Me"|
|"for the last week"|"For The Last Week"|

## 정답 소스 코드
```cpp

#include <string>
#include <cctype>

using namespace std;

string solution(string s) {
    // 새로운 단어의 시작인지 확인하는 플래그 (문자열의 맨 첫 글자는 항상 단어의 시작)
    bool is_new_word = true; 

    for (int i = 0; i < s.length(); i++) {
        // 1. 공백을 만나면 그대로 두고, 다음 글자가 단어의 시작임을 표시
        if (s[i] == ' ') {
            is_new_word = true;
            continue;
        }

        // 2. 단어의 첫 글자인 경우
        if (is_new_word) {
            if (isalpha(s[i])) {
                s[i] = toupper(s[i]); // 알파벳이면 대문자로 변환
            }
            is_new_word = false; // 첫 글자 처리가 끝났으므로 플래그 해제
        } 
        // 3. 단어의 첫 글자가 아닌 뒤쪽 글자들인 경우
        else {
            if (isalpha(s[i])) {
                s[i] = tolower(s[i]); // 알파벳이면 무조건 소문자로 변환
            }
        }
    }

    return s; // 원본 s를 직접 수정하여 반환
}
```

## Comments:


* 공백 완벽 유지: 공백(' ')이 나오면 변환 없이 패스하므로 연속된 공백이나 앞뒤 공백이 완벽하게 보존됩니다.
* 숫자 뒤 소문자 처리: 첫 글자가 숫자일 때는 isalpha 조건에 걸리지 않아 대문자 변환을 건너뛰고 바로 is_new_word = false가 되므로, 그 뒤에 오는 대문자 알파벳들을 정상적으로 소문자로 깎아줍니다.


처음에 했는데 안된것. 안된 이유

실패하는 결정적인 원인 3가지

① 연속된 공백과 공백 유지 실패 (`stringstream` 문제)

- **문제점**: `stringstream >> word`는 공백이 **몇 개든 상관없이 전부 무시**하고 단어만 추출합니다.
- **예시**: 입력이 `"apple banana"`(공백 3개)라면 `wordList`에는 `["apple", "banana"]`만 들어갑니다. 이후 작성하신 코드는 단어 사이에 공백을 **무조건 1개만** 채워 넣으므로 `"apple banana"`가 되어 **원본 공백 구조가 파괴**됩니다. 만약 문자열 앞뒤에 공백이 있는 경우도 모두 지워집니다.

② 첫 번째 단어만 대문자로 만드는 로직 문제

- **문제점**: 이전 질문에서 "첫 번째 단어만 대문자로, 뒤는 소문자로" 바꾸고 싶다고 하셨는데, 현재 코드의 `else` 문 안을 보면 **모든 단어(`wordList`에 있는 모든 요소)의 첫 글자를 대문자**로 만들고 있습니다.
- **해결**: `index == 0`일 때만 첫 글자를 대문자로 만들고, `index > 0`일 때는 첫 글자도 소문자로 만드는 조건 분기가 빠져 있습니다.

③ 빈 문자열 접근 위험 (`it[0]` 런타임 에러 가능성)

- 문자열이 비어있을 가능성은 낮지만, 혹시라도 `it`가 빈 문자열(`""`)일 때 `it[0]`에 접근하면 프로그램이 강제 종료(런타임 에러)될 수 있습니다. 안전하게 `!it.empty()` 체크를 해주는 것이 좋습니다.

```cpp
string solution(string s)

{

    string answer = "";

    stringstream ss(s);

    string word;

    vector<string> wordList;

    int index = 0;

    ;

  

    while(ss >> word)

    {

        wordList.push_back(word);

    }

  

    for(string it : wordList)

    {

        if(isdigit(it[0]))

        {

            answer += it;            

        }

        else

        {

            it[0] = toupper(it[0]);

            for(int i =1; i < it.size(); i++)

            {

                it[i] = tolower(it[i]);

            }

  

            answer += it;

        }

  

        index++;  

  

        if (index < wordList.size())

        {

            answer += " ";

        }      

    }

  

    return answer;

}
```
