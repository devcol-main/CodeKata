### 힌트

* 10진수를 3진수로 변환하려면 해당 숫자가 0이 될 때까지 **3으로 계속 나누고, 나머지를 역순(마지막 나머지부터 처음 나머지 순)**으로 나열
**변환 단계:**

1. **나누기:** 10진수를 3으로 나눕니다.
2. **나머지 기록:** 몫과 나머지를 구합니다. 나머지는 항상 0, 1, 2 중 하나입니다.
3. **반복:** 몫이 0이 될 때까지 1~2 과정을 반복합니다.
4. **나열:** 구한 나머지들을 **맨 마지막에 나온 나머지부터 맨 처음 나온 나머지 순서**로 적습니다

<br>

예시: 45 (10진수를 3진법으로 변환)
* (45 / 3 = 15) ... **나머지 0**
* (15 / 3 = 5) ... **나머지 0**
* (5 / 3 = 1) ... **나머지 2**
* (1 / 3 = 0) ... **나머지 1** (몫이 0이므로 종료)

**결과:** 나머지를 거꾸로 읽으면 (1200)이 됨


* 3진법은 0, 1, 2 세 개의 숫자만 사용하여 수를 표현하며, 자리수가 올라갈 때마다 3배씩 증가 (1, 3, 9, 27...). 3진수를 10진수로 바꿀 때는 각 자리 숫자에 (3^n)을 곱해 더하고, 10진수를 3진수로 바꿀 때는 3으로 나눈 나머지를 역순으로 나열

* 3진수를 10진수으로 변환 (3진수 -> 10진수)
	* 예시: 1200 (3진법)
	* (1x3^3) + (2x3^2) + (0x3^1) + (0x3^0)
	* = 1x27 + 2x9 + 0x3 + 0x1 = 27 + 18 + 0 + 0 = 45

## 정답 소스 코드
```cpp
#include <numeric>

#include <string>
#include <vector>
#include <cmath>
#include <algorithm>

using namespace std;
int solution(int n) {
    int answer = 0;

    vector<int> ans;

    while (true)
    {
        
        ans.push_back(n % 3);
        n /= 3; 

        if (n == 0)
        {
            break;
        }
    }

    reverse(ans.begin(), ans.end());

    int sum =0;

    for (int i = 0; i < ans.size(); i++)
    {
        sum += ans[i] * pow(3, i);
    }

    return answer = sum;
}

```
