* seoul의 element중 "Kim"의 위치 x를 찾기

### 문제 해석
* 배열로 받고 순회 하면서 몇번째에서 찾았는지, 그리고 찾으면 나가기.

## 정답 소스 코드
```cpp
#include <string>
#include <vector>

#include <iostream>
using namespace std;

string solution(vector<string> seoul) {
    int n = 0;

    for (auto findkim : seoul)
    {
        if (findkim == "Kim")
        {
            break;
        }
        n++;
    }


    string answer = "김서방은 " + to_string(n) + "에 있다"; // o_string(n)을 사용하여 int를 string으로 변환 후 결합

    //string answer = "kim at " + to_string(n) + "th";

    return answer;
}
```
