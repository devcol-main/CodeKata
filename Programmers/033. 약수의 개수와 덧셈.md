###### 문제 설명

두 정수 `left`와 `right`가 매개변수로 주어집니다. `left`부터 `right`까지의 모든 수들 중에서, 약수의 개수가 짝수인 수는 더하고, 약수의 개수가 홀수인 수는 뺀 수를 return 하도록 solution 함수를 완성해주세요.

---

##### 제한사항

- 1 ≤ `left` ≤ `right` ≤ 1,000

---

##### 입출력 예

|left|right|result|
|---|---|---|
|13|17|43|
|24|27|52|

---

##### 입출력 예 설명

- 다음 표는 13부터 17까지의 수들의 약수를 모두 나타낸 것입니다.

|수|약수|약수의 개수|
|---|---|---|
|13|1, 13|2|
|14|1, 2, 7, 14|4|
|15|1, 3, 5, 15|4|
|16|1, 2, 4, 8, 16|5|

- 따라서, 13 + 14 + 15 - 16 + 17 = 43을 return 해야 합니다.

- 다음 표는 24부터 27까지의 수들의 약수를 모두 나타낸 것입니다.

|수|약수|약수의 개수|
|---|---|---|

|26|1, 2, 13, 26|4|
|27|1, 3, 9, 27|4|

- 따라서, 24 - 25 + 26 + 27 = 52를 return 해야 합니다.

	* 즉 약수는 나누어 떨어지는 수 (n % i == 0)

## 문제 풀이 과정

### 문제 나누기
* 매개변수의 약수 개수 확인
	* n 의 약수가 짝수면 +n
	* n 의 약수가 홀수면 -n


### 문제 해석

## 정답 소스 코드
```cpp
#include <string>
#include <vector>

using namespace std;

int solution(int left, int right) {
    int answer = 0;
    vector<int> sum;    

    // <= : since need to include right
    for (int i = left; i <= right;i++)
    { 
        int primeNumAmount = 0;

        for (int j = 1; j <= i;j++)
        {
            //약수
            if (i % j == 0)
            {
                ++primeNumAmount;
            }
        }
        // 배열에 담기
        // 짝수면 +, 홀수 면 -
        if (primeNumAmount % 2 == 0)
        {
            sum.push_back(i);
        }
        else
        {
            sum.push_back(-i);
        }
    }

    for (auto it : sum)
    {
        answer += it;        
    }

    return answer;
}

```

* N 이 클 때((10^{9}) 이상) 사용하며, 약수의 쌍을 이용하여 속도를 높인다고 한다
```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <algorithm>

std::vector<int> getDivisorsFast(int n) {
    std::vector<int> divisors;
    for (int i = 1; i <= std::sqrt(n); i++) {
        if (n % i == 0) {
            divisors.push_back(i);
            if (i * i != n) { // 제곱근이 아닐 경우 짝 약수도 추가
                divisors.push_back(n / i);
            }
        }
    }
    std::sort(divisors.begin(), divisors.end()); // 정렬 필요
    return divisors;
}
```
