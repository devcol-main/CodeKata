###### 문제 설명

경화는 과수원에서 귤을 수확했습니다. 경화는 수확한 귤 중 'k'개를 골라 상자 하나에 담아 판매하려고 합니다. 그런데 수확한 귤의 크기가 일정하지 않아 보기에 좋지 않다고 생각한 경화는 귤을 크기별로 분류했을 때 서로 다른 종류의 수를 최소화하고 싶습니다.

예를 들어, 경화가 수확한 귤 8개의 크기가 [1, 3, 2, 5, 4, 5, 2, 3] 이라고 합시다. 경화가 귤 6개를 판매하고 싶다면, 크기가 1, 4인 귤을 제외한 여섯 개의 귤을 상자에 담으면, 귤의 크기의 종류가 2, 3, 5로 총 3가지가 되며 이때가 서로 다른 종류가 최소일 때입니다.

경화가 한 상자에 담으려는 귤의 개수 `k`와 귤의 크기를 담은 배열 `tangerine`이 매개변수로 주어집니다. 경화가 귤 k개를 고를 때 크기가 서로 다른 종류의 수의 최솟값을 return 하도록 solution 함수를 작성해주세요.

---

##### 제한사항

- 1 ≤ `tangerine`의 원소 ≤ 10,000,000

이 문제는 수확한 귤 중 \(k\)개를 골라 상자에 담을 때, **귤의 크기 종류를 최소화**하는 그리디 알고리즘 문제입니다. 핵심은 ==**개수가 많은 종류의 귤부터 차례대로 상자에 담는 것**==입니다. 

### 문제 해설 및 힌트

1. **빈도수 계산:** 우선 크기별로 귤이 몇 개씩 있는지 세야 합니다. `map`이나 크기를 인덱스로 하는 배열(`count`)을 사용하여 각 크기별 귤의 개수를 저장합니다. 
2. **내림차순 정렬:** 크기 종류는 상관없이, **가장 많은 개수를 가진 귤 종류부터 상자에 채워야** 상자에 들어가는 귤의 종류(종류의 수)를 최소화할 수 있습니다. 따라서 빈도수를 기준으로 내림차순 정렬합니다. 
3. **그리디하게 담기:** 개수가 가장 많은 종류부터 차례대로 누적하여 더합니다. 누적된 귤의 개수가 \(k\) 이상이 되는 순간의 귤 종류 개수가 정답이 됩니다.

## 정답 소스 코드
```cpp
#include <string>
#include <vector>
#include <map>
#include <algorithm>

using namespace std;

int solution(int k, vector<int> tangerine) {
    int answer = 0;
    
    // 1. 크기별 귤의 개수 카운트
    map<int, int> counts;
    for (int size : tangerine) {
        counts[size]++;
    }
    
    // 2. map의 value(귤의 개수)만 추출하여 vector에 저장
    vector<int> count_vec;
    for (auto const& [key, val] : counts) {
        count_vec.push_back(val);
    }
    
    // 3. 귤의 개수가 많은 순서대로 내림차순 정렬
    sort(count_vec.begin(), count_vec.end(), greater<int>());
    
    // 4. 개수가 많은 종류부터 k개가 될 때까지 담기
    int current_sum = 0;
    for (int count : count_vec) {
        current_sum += count;
        answer++; // 상자에 종류 추가
        
        if (current_sum >= k) {
            break; // k개를 모두 담았으면 종료
        }
    }
    
    return answer;
}


```
