###### 문제 설명

효진이는 멀리 뛰기를 연습하고 있습니다. 효진이는 한번에 1칸, 또는 2칸을 뛸 수 있습니다. 칸이 총 4개 있을 때, 효진이는  
(1칸, 1칸, 1칸, 1칸)  
(1칸, 2칸, 1칸)  
(1칸, 1칸, 2칸)  
(2칸, 1칸, 1칸)  
(2칸, 2칸)  
의 5가지 방법으로 맨 끝 칸에 도달할 수 있습니다. 멀리뛰기에 사용될 칸의 수 n이 주어질 때, 효진이가 끝에 도달하는 방법이 몇 가지인지 알아내, 여기에 1234567를 나눈 나머지를 리턴하는 함수, solution을 완성하세요. 예를 들어 4가 입력된다면, 5를 return하면 됩니다.

##### 제한 사항

- n은 1 이상, 2000 이하인 정수입니다.

##### 입출력 예

|n|result|
|---|---|
|4|5|
|3|3|

입출력 예 #1  
위에서 설명한 내용과 같습니다.

(2칸, 1칸)  
(1칸, 2칸)  
(1칸, 1칸, 1칸)  
총 3가지 방법으로 멀리 뛸 수 있습니다.

### 힌트
- **마지막 직전 단계 생각하기**  
    효진이가 마지막 칸에 도달하기 직전의 행동은 딱 두 가지뿐입니다. **바로 앞 칸에서 1칸을 뛰었거나**, 아니면 **두 칸 전에서 2칸을 뛰었거나**입니다.
    - 예시: 4번째 칸에 도달하는 방법은 (3번째 칸에 도달하는 방법의 수)와 (2번째 칸에 도달하는 방법의 수)를 더한 것과 같습니다.
- **피보나치 수열의 규칙**  
    1번째 칸에 가는 방법은 1가지이고, 2번째 칸에 가는 방법은 2가지입니다. 3번째 칸은 앞의 두 값을 더한 3가지가 됩니다. 즉, **현재 칸의 방법 수는 이전 두 칸의 방법 수를 더한 값**이 되는 피보나치 수열의 규칙을 따릅니다.
- **나머지 연산의 타이밍**  
    정답이 매우 커질 수 있으므로, 마지막에 한 번만 나누면 계산 과정에서 숫자가 범위를 벗어나 버립니다. 따라서 **매번 이전 두 값을 더할 때마다 곧바로 1234567로 나눈 나머지**를 구해서 저장해야 안전합니다.
- **공간 절약하기**  
    배열을 2000개까지 만들 필요 없이, 단 3개의 변수(두 칸 전, 한 칸 전, 현재 칸)만 사용해서 값을 계속 갱신해 나가면 메모리를 아낄 수 있습니다.

## 정답 소스 코드
```cpp

#include <vector>

using namespace std;

int solution(int n) {
    // n이 1일 때는 바로 1을 반환합니다.
    if (n == 1) return 1;
    
    // n이 2일 때는 바로 2를 반환합니다.
    if (n == 2) return 2;
    
    // 두 칸 전의 방법 수 (n이 1일 때의 값)
    long long prev2 = 1;
    // 한 칸 전의 방법 수 (n이 2일 때의 값)
    long long prev1 = 2;
    // 현재 칸의 방법 수
    long long current = 0;
    
    // 3번째 칸부터 n번째 칸까지 반복하며 값을 갱신합니다.
    for (int i = 3; i <= n; ++i) {
        // 이전 두 칸의 값을 더한 뒤, 문제에서 요구한 숫자로 나머지를 구합니다.
        current = (prev1 + prev2) % 1234567;
        
        // 다음 칸 계산을 위해 변수들을 한 칸씩 이동시킵니다.
        prev2 = prev1;
        prev1 = current;
    }
    
    return current;
}
```
