###### 문제 설명

2016년 1월 1일은 금요일입니다. 2016년 a월 b일은 무슨 요일일까요? 두 수 a ,b를 입력받아 2016년 a월 b일이 무슨 요일인지 리턴하는 함수, solution을 완성하세요. 요일의 이름은 일요일부터 토요일까지 각각 `SUN,MON,TUE,WED,THU,FRI,SAT`

입니다. 예를 들어 a=5, b=24라면 5월 24일은 화요일이므로 문자열 "TUE"를 반환하세요.

##### 제한 조건

- 2016년은 윤년입니다.
- 2016년 a월 b일은 실제로 있는 날입니다. (13월 26일이나 2월 45일같은 날짜는 주어지지 않습니다)

#### 입출력 예

|a|b|result|
|---|---|---|
|5|24|"TUE"|

### 힌트
- **31일**: 1월, 3월, 5월, 7월, 8월, 10월, 12월
- **30일**: 4월, 6월, 9월, 11월
- **28일 또는 29일**: 2월 (윤년에는 29일) 

* **윤년(Leap Year)**: 4년에 한 번씩 2월에 하루(29일)를 추가하여 366일로 만든 해

## 정답 소스 코드
```cpp
#include <string>
#include <vector>

using namespace std;

// a month | b days
string solution(int a, int b) {
    // 31일: 1월, 3월, 5월, 7월, 8월, 10월, 12월
    // 30일: 4월, 6월, 9월, 11월
    // 28일 또는 29일: 2월(윤년에는 29일)

    string answer = "";    
    int totalDays = 0;
   
    const int monthDays[] = {31,29,31,30,31,30,31,31,30,31,30,31};

    //string daysName[] = { "SUN","MON","TUE","WED","THU","FRI","SAT"};
    string daysName[] = { "THU","FRI","SAT", "SUN","MON","TUE","WED" };
    
    for (int i = 1; i < a; i++)
    {        
        totalDays += monthDays[i-1];     
    }

    totalDays += b;  
    totalDays %= 7;

    answer = daysName[totalDays];

    
    return answer;
}

```

## Comments:
* 날짜 설정에서 string daysName[] = { "THU","FRI","SAT", "SUN","MON","TUE","WED" }; 한이유는 1월 1일이 금요일이라, day 가 1이였을 때 금요일로 설정하기 위해서 이렇게함.
* 물론 string daysName[] = { "SUN","MON","TUE","WED","THU","FRI","SAT"}; 하고 추가 계산을 아래서 하는게 더 깔끔하지만, 그냥 문제 풀기니깐 걍 ㄱㄱ
