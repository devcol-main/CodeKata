###### 문제 설명

철호는 수열을 가지고 놀기 좋아합니다. 어느 날 철호는 어떤 자연수로 이루어진 원형 수열의 연속하는 부분 수열의 합으로 만들 수 있는 수가 모두 몇 가지인지 알아보고 싶어졌습니다. 원형 수열이란 일반적인 수열에서 처음과 끝이 연결된 형태의 수열을 말합니다. 예를 들어 수열 [7, 9, 1, 1, 4] 로 원형 수열을 만들면 다음과 같습니다.

## 문제 풀이 과정

- **원형 수열 구조 해결하기 (배열 2배 늘리기)**
    - 처음과 끝이 연결된 원형 수열은 인덱스가 끝을 넘어 다시 앞으로 돌아옵니다.
    - 이를 쉽게 해결하는 가장 좋은 방법은 주어진 `elements` 배열을 뒤에 한 번 더 이어 붙여 **길이가 2배인 배열**을 만드는 것입니다.
    - 예를 들어 `[7, 9, 1, 1, 4]`라면 `[7, 9, 1, 1, 4, 7, 9, 1, 1, 4]`로 만듭니다. 이렇게 하면 인덱스 초과 처리(나머지 연산) 없이 일반적인 선형 배열처럼 접근할 수 있습니다.
- **중복 없는 합 저장하기 (`std::set`)**
    - 문제에서 요구하는 것은 "만들 수 있는 수의 **개수**"이므로 같은 합이 여러 번 나와도 한 번만 세어야 합니다.
    - C++의 `std::set` 자료구조는 원소를 삽입할 때 자동으로 중복을 제거해 줍니다. 모든 합을 `set`에 넣은 뒤 최종적으로 `set.size()`를 구하면 됩니다.
- **반복문 구성하기**
    - 바깥쪽 반복문은 부분 수열의 **길이**(\(1\)부터 원본 배열의 길이까지)를 결정합니다.
    - 안쪽 반복문은 부분 수열이 **시작하는 위치**를 결정합니다.
    - 시작 위치부터 지정된 길이만큼 더한 값을 `set`에 추가합니다.

## 정답 소스 코드
```cpp

#include <string>
#include <vector>
#include <set>

using namespace std;

int solution(vector<int> elements) {
    int n = elements.size();
    set<int> unique_sums; // 중복을 제거하며 합을 저장할 셋
    
    // 1. 원형 수열을 처리하기 위해 배열을 2배로 늘림
    vector<int> extended_elements = elements;
    for (int i = 0; i < n; i++) {
        extended_elements.push_back(elements[i]);
    }
    
    // 2. 부분 수열의 길이(len)를 1부터 n까지 늘려가며 확인
    for (int len = 1; len <= n; len++) {
        // 시작 인덱스(start) 설정
        for (int start = 0; start < n; start++) {
            int sum = 0;
            // 시작 위치부터 지정된 길이만큼 원소들을 더함
            for (int k = 0; k < len; k++) {
                sum += extended_elements[start + k];
            }
            // 구해진 합을 set에 삽입 (자동 중복 제거)
            unique_sums.insert(sum);
        }
    }
    
    // 3. set에 저장된 유일한 합의 개수를 반환
    return unique_sums.size();
}

```

## Comments:

만약 더 효율적으로 풀고 싶다면, 매번 합을 처음부터 다시 더하는 대신 **이전 인덱스의 합에서 앞의 원소를 빼고 뒤의 원소를 더하는 '슬라이딩 윈도우(Sliding Window)'** 기법을 적용하여 시간 복잡도를 \(O(N^3)\)에서 \(O(N^2)\)로 크게 단축할 수 있습니다.
