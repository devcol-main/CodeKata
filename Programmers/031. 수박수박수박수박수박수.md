|n|return|

|3|"수박수"|
|4|"수박수박"|

## 문제 풀이 과정

### 문제 해석

입력값은 두개의 문자가 반복되는 형식이니깐
* i % 2 == 0 - > 사용해서, 0 포함, 짝수면 처음 문자 아니면 두번째 문자 출력.

---
## 정답 소스 코드
```cpp
#include <string>
#include <vector>

using namespace std;

string solution(int n) {
    string answer = "";

    string first = "수";
    string second = "박";

    for (int i = 0; i < n;i++)
    {
        if (i % 2 == 0)
            answer += first;
        else
            answer += second;
    }

    return answer;
}
```
