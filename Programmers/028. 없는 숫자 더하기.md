###### 문제 설명

0부터 9까지의 숫자 중 일부가 들어있는 정수 배열 `numbers`가 매개변수로 주어집니다. `numbers`에서 찾을 수 없는 0부터 9까지의 숫자를 모두 찾아 더한 수를 return 하도록 solution 함수를 완성해주세요.

---

##### 제한사항

- 1 ≤ `numbers`의 길이 ≤ 9
    - 0 ≤ `numbers`의 모든 원소 ≤ 9
    - `numbers`의 모든 원소는 서로 다릅니다.

---

##### 입출력 예

|numbers|result|
|---|---|
|[1,2,3,4,6,7,8,0]|14|
|[5,8,4,0,6,7,9]|6|

---

##### 입출력 예 설명

**입출력 예 #1**

- 5, 9가 `numbers`에 없으므로, 5 + 9 = 14를 return 해야 합니다.

**입출력 예 #2**

- 1, 2, 3이 `numbers`에 없으므로, 1 + 2 + 3 = 6을 return 해야 합니다.

---
### 기본 코드
```cpp
#include <string>
#include <vector>

using namespace std;

int solution(vector<int> numbers) {
    int answer = -1;
    return answer;
}
```

## 문제 풀이 과정

### 문제 나누기
* 배열이 1~9 까지 들어오고, 원소는 서로 다르다

### 문제 해석
* 아마 더 좋은 답이 있겠지만, 나는 그냥 쉽게 생각했다.
* 이 문제에서 최대로 나올 수 있는 답은 1~9를 다 더한 수. (들어올 수 있는 수의 경우가 0~ 9 니깐)
	* 그래서 그냥 최대 수 를 구한뒤, 들어오온 숫자를 빼면, 최대 수가 되기 위한 합이 나옴 = 빠진 숫자들의 합합

---
## 정답 소스 코드
```cpp
#include <string>
#include <vector>

using namespace std;

int solution(vector<int> numbers) {
    int answer = -1;

    int allSum =0;
    // 0~9
    for (int i = 0; i < 10; i++)
    {
        allSum += i;
    }

    int partSum =0;
    for (auto it : numbers)
    {
        partSum += it;
    }

    answer = allSum - partSum;

    return answer;
}
```
